# Codex PowerToys VS Code Extension

This desktop extension provides Resources, Skills, MCPs, Agents, and Info views over the shared Codex PowerToys core. Install the generated VSIX with `code --install-extension <file>.vsix`.

The extension runs in a desktop Node extension host and resolves global Codex paths on that host. It discovers plugin manifests, remote-install metadata, plugin skills, and plugin `.mcp.json` files, while keeping plugin source files read-only.

All four resource panes are native multi-select TreeViews. Resources has Global (`~/`) and Workspace roots; each scope contains Plugins, MCPs, and Skills groups, with plugin skills under `skills/` and plugin MCPs under `.mcp.json`. Skills and MCPs are also available as flat alphabetical lists. Type filters update while typing, each item shows its source path in a tooltip, and plugin rows identify the plugin by name while showing workspace plugin roots relative to the active workspace. Every pane offers Copy Full Path and Copy Relative Path. Relative paths use the active workspace root.

Resource rows use status glyphs followed by type icons: `🔌` plugin, `🧰` MCP, `🔨` tool, `💪` skill, and `🤖` agent. Resource group rows use the same type glyphs, and empty groups are omitted. Enabled winners use `✅`, enabled superseded records use `☑️`, disabled winners use `❌`, and records superseded by disabled winners use `✖️`; superseded records can be shown or hidden independently from the Resources, Plugins, MCPs, and Skills pane toolbars, while Agents has no superseded toggle. Enabled MCPs are queried one at a time in the background; successful tools and failed probes are cached, while Load MCP Tools forces a re-query. Use the icon toolbar or an item context menu to refresh, filter, enable/disable, cut, copy, paste, rename, delete, and load MCP tools. Resources initially expand only the Global and Workspace roots; all sub-nodes start collapsed. Its toolbar expands non-skill nodes while keeping skill rows and their supporting entries collapsed, or collapses every non-root node while restoring both roots to expanded state. Field-labelled workspace tooltips use workspace-relative paths, while global paths remain canonical; skill, MCP, plugin, and tool descriptions are included when available. Clicking a plugin or choosing Open Plugin Manifest opens `.codex-plugin/plugin.json`, and Enable/Disable commands are disabled when their opposite state already applies. Moves and deletes are confirmed with modal dialogs, and paste conflicts provide Skip all, Replace all, Decide each, or Cancel choices. Dragging is a confirmed move because the native VS Code TreeView API does not expose Ctrl-drag modifier state; Copy/Paste is the supported copy workflow.

The Agents view opens global and workspace roots expanded by default. Selecting a skill, MCP, agent, plugin, or tool updates the Info panel; MCP tools from the background cache appear in both MCP-capable panes.
